# Zettly CLI Implementation Plan

1. **Done:** standalone Node CLI package with host config, bearer client, human/JSON output, confirmation prompts, DPAPI token vault and hidden token prompt.
2. **Done:** `/api/v1` routes for dashboard, todos/notes, tags, focus, habits, organizations, drawings, attachments, push, profile and token management. Protected routes enforce the `zettly:cli` ability; organization/admin routes preserve membership and role checks. Public account lifecycle routes are rate-limited.
3. **Done:** graph JSON export and super-admin-only rebuild; system status, admin monitor and test-email endpoints.
4. **Done:** CLI operations and examples documented in `cli/README.md`, including Dashboard and text Eisenhower board; remaining browser-only boundaries are push permission grants and visual canvas editing.
5. **Verified:** Laravel route boot registers 78 `/api/v1` routes; all 74 protected routes include `abilities:zettly:cli`, all 4 public auth routes are throttled, and the signed verification route has `auth:sanctum`, `signed` and throttling. Production read-only smoke passed for 16 CLI operations. CLI unit suite passes 7/7; frontend suite passes 77/77 from the installed main checkout. Attachment upload/download/delete passed a production round-trip with matching SHA-256 and cleanup.
6. **Done:** Profile password change is available through CLI and uses current-password validation plus Laravel's default password policy.
7. **Done:** Account registration, email/password login, password recovery, verification resend and signed email verification are available in the CLI. Public auth routes are throttled; verification requires the signed web URL, matching configured host and the user's CLI token. Host validation requires HTTPS except for loopback development.
8. **Released:** PRs #7–#10 are merged. Production on `bw-server-clean` runs `e621800449a728cbb00b6a15c2e6dacdcc229c4d`; PHP-FPM and nginx are active. Attachment storage uses the VM-managed service account with bucket-scoped object access; the missing key-file setting was removed from production `.env` after preserving a private backup.
9. **Remaining browser boundaries:** The browser must grant notification permission. TLDraw canvas visual manipulation remains in the browser; CLI supports drawing document JSON and shape records.
